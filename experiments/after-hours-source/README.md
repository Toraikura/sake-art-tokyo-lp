# 水源カード → 抽象水面：控えめな実験

基準は `5b2bfdc55465392bba9d1176861d0e20220efb3d` の完成版です。`experiments/after-hours-water/`、ルートLP、商品・実物ラベル・漫画、元ゲームは変更していません。新規ページとテストだけを追加する実験ブランチです。

## 開く

リポジトリルートから `python3 -m http.server 4190 --bind 127.0.0.1` を起動してください。

- 実験: <http://127.0.0.1:4190/experiments/after-hours-source/>
- 現行: <http://127.0.0.1:4190/experiments/after-hours-water/>

このURLはサーバーを起動したMac専用です。main／Pagesへは反映しません。

## 実装

- 水源カードはPCで各174×約99px、390pxで各159×約91px、375pxで各153×約87px。横並びで水面の上に置き、カード全体を押せます。
- 浦里の画像は筑波山と田園。線の起点は元画像座標 `(570,595)`、山の中腹です。土田は石鉢周辺へ表示範囲を寄せ、こぼれ水の `(469,967)` を起点にしました。ししおどし本体を起点にはしていません。
- 元PNGはバイト単位で保持。SVGの表示範囲だけでトリミングしています。画像は提供されたイラストであり、実際の取水地点を検証した資料としては扱っていません。
- 線は選択中の1本。0.55 CSS px、浦里16％／土田18％を最大に途中から消える勾配です。水面上39％の位置までに溶け込ませます。細い線でも長いと補助線に見えたため、初期案から短く・薄くしました。
- 線を常時動かす処理、粒子、飛沫、発光、着水リングはありません。既存の動く水面の上に静かな流入を示す構成です。切替時だけ0.55秒で入れ替わります。
- 水面の描画関数は完成版と完全一致。既存CSS・ゲーム・商品・ラベルは相対参照で再利用します。新しい3Dライブラリや依存パッケージはありません。
- カードは水面のボタン領域と分離しています。選択操作だけで大きな波紋は起きません。水面色、SIDE、商品CTA、商品選択表示、エチケット、ゲームの紹介先が連動します。
- `prefers-reduced-motion` と「動きを止める」で追加の切替トランジションを停止。SVGの座標更新はリサイズ時のみで、追加のrequestAnimationFrameループはありません。
- 実験ページだけ、スマホのグリッド幅を明示し、見出し・カード・SIDEが切れないよう調整しています。

## 現行版との比較・推奨

**完成版への採用は「保留」。水源カードによる選択は採用候補です。**

| 観点 | 現行版 | この実験 |
| --- | --- | --- |
| 最初に目に入るもの | 抽象水面とコピーに集中 | 水面を主役に、小さな土地の絵が加わる |
| 選択対象 | 軽やか／濃密という気分 | 浦里／土田という具体的なつくり手 |
| 水と酒のつながり | 読み進めて知る | 絵から水面、選んだ蔵の一本へ進む入口をつくる |
| 水の線 | なし | 細く短い1本。探すと分かる程度 |
| 見た目の評価 | 要素が少なく、静けさが最も強い | 方向性は合うが、線の存在が価値を足すかはまだ判断材料が不足 |
| 描画 | 既存WebGL／2D fallback | 同じ描画関数。新しい描画ループなし |
| 初回画像量 | 既存素材のみ | 元PNG2枚、合計4,201,459 bytesが追加される |

PC・375px・390pxでは、カードが水面を押しのける大きさではなく、石鉢の構図も適切です。線は最終版でさらに弱めました。派手さはありませんが、「水源→水→酒」が初見で伝わるという効果までは確認できていません。説明なしで選んでもらい、線に意味を感じなければ、線を加えない現行版の静けさを優先します。

画像は原本のままなので、公開採用を決める場合にはカード用の配信用画像を軽量化し、iPhone Safariで通信を含む初回表示と見え方を確認する余地があります。今回のローカル確認を実機・低速回線の合格とは扱いません。

## 検証

`tests/source-water/test_ui.py` が実HTTPで以下を検証します。

- PC1440px／390px／375px、横はみ出し・クリップによる文字切れ、カードの押下サイズ。
- 両カード、SIDE／CTA／ラベルの連動、キーボード、選択だけでは波紋が増えないこと。
- 原画座標からSVGの表示座標への起点一致、線幅・不透明度、選択中の線だけ表示。
- reduced-motion、手動停止、再開後の切替。
- 元ゲームの実iframe起動、初手まで停止、実配置、自然な30秒対戦、再戦、閉じる、商品詳細への遷移とブラウザバック。
- 元画像のHTTP200、アプリ例外・HTTPエラー。既存favicon未配置による404は区別して記録。

Python環境にPlaywrightが必要です。既存Chromeは `PLAYWRIGHT_EXECUTABLE_PATH`、証跡先は `EVIDENCE_DIR` で指定できます。

```sh
node --check experiments/after-hours-source/site.js
node --check experiments/after-hours-source/intuitive.js
node --check experiments/after-hours-source/source-water.js
python tests/source-water/test_ui.py
```

同じMacのheadless Chromeで各3秒の簡易応答比較も実施。現行／実験とも390px・1440pxのrAF間隔中央値は約16.7ms、50ms超のlong taskは0件でした。これは単発のローカル応答計測で、iPhoneの実FPSや初回ダウンロード速度の測定ではありません。

未検証: iPhone Safari実機、低速回線での初回画像表示、初見ユーザーの意味理解、好み・高級感に関する第三者評価。比較評価は制作上の判断であり、ユーザーテスト結果ではありません。
